# RELEASE-1.0 — финализация Talaria OS для внешних пользователей

План сессии финализации (2026-08-24). Работаем по пунктам, коммит на пункт
(`R<блок>.<пункт>: <что>`), гейт неизменен: `test.sh` (FAIL=0; счётчик — README) + `validate.sh`.
Статусы: [ ] todo, [~] в работе, [x] сделано.

## 0. Зафиксированные решения (согласовано с владельцем)

- **Scope v1.0: QEMU/KVM-only.** Голое железо (UEFI/ACPI/NIC-драйверы, TODO §5) —
  roadmap, вне v1.0. Явно фиксируется в PRODUCT.md.
- **Опенсорс: Apache-2.0 + CLA.** Публикация в ОТДЕЛЬНУЮ публичную репу (форк из
  этой); эта репа — приватный апстрим, после форка публичная становится основной
  для открытого кода, приватное — оверлеем.
- **Именование:** официальное имя **Talaria OS**; поисковый/технический токен
  **TalariaOS**; хэндлы `talaria-os`; короткий префикс **TAL** (TAL-RFC-NNN,
  TAL_* env); нагрузка — **cell**. Категория-тэглайн: «latency-first
  single-application OS (unikernel-style), Linux-ABI compatible».
  НЕ используем: «microkernel» (неверно технически), «TalOS» (коллизия с Talos
  Linux), «Talaria Linux» (не Linux + чужой ТЗ).
- **Патенты:** решение (US provisional по механизмам синхронизации) принимается
  ПЕРЕД публикацией — чекпойнт в блоке 5, до того публичных раскрытий нет.
- **Модель:** as-is, без гарантий и обязательств по поддержке; платная поддержка
  по отдельному соглашению; донаты (FUNDING.yml).
- **Копирайт: Denis Tishkov.** В NOTICE и README обязательная атрибуция: код и
  платформа в целом разработаны с помощью ИИ-агента (Claude Code, модель
  Claude Fable 5, Anthropic).
- **Язык доков: русский.** Английские версии (README и далее) — отдельным
  этапом после v1.0-preview, не в этой сессии.
